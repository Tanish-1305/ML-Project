## Project objective

1. Forecast next-month state/region unemployment rates using past unemployment, estimated employment and labour-force participation.
2. Compare Linear Regression, Ridge Regression and k-Nearest Neighbours (k-NN) with a persistence baseline.
3. Cluster state-level COVID shock-and-recovery trajectories using K-Means and hierarchical clustering.

## Dataset

Primary source: [Unemployment in India — Kaggle (Gokul Raj / CMIE-based)](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

Download the file named **`Unemployment in India.csv`** from the dataset page and place it at:

`data/raw/Unemployment in India.csv`

The repository intentionally does not redistribute the dataset. Check the dataset page for its current licence and attribution requirements.

The source file is expected to contain columns similar to:

- `Region`
- `Date`
- `Frequency`
- `Estimated Unemployment Rate (%)`
- `Estimated Employed`
- `Estimated Labour Participation Rate (%)`
- `Area` (Rural / Urban)

The source file contains rural/urban observations. The script combines them into a state-region-month series using estimated labour force as weights. This makes the modelling unit consistent with the assignment's state-wise monthly objective. The aggregation is an analytical choice and is documented in the script.

## Method

### Forecasting target

For each region and month *t*, the target is unemployment rate at the next observed consecutive month (*t+1*). Rows with a missing month between the current and target observations are not used as one-step-ahead pairs.

Predictors:
- Current unemployment rate
- One-month lagged unemployment rate
- Two-month lagged unemployment rate
- Current estimated employed
- Current estimated labour participation rate
- Region (one-hot encoded)

### Models

- Persistence baseline: next month's rate = current month's rate
- Linear Regression
- Ridge Regression
- k-NN Regression

The final three unique months are held out as a chronological test period. All preprocessing is fitted on the training data only. Since this dataset has a relatively short time span, results should be interpreted as a small-sample demonstration, not a production forecasting system.

### Clustering

Each region is represented by:
- Pre-shock average unemployment rate (May 2019–February 2020 where available)
- Peak shock-period unemployment rate (March–May 2020)
- Shock increase relative to pre-shock average
- June 2020 unemployment rate (where available)
- Change from shock peak to June 2020

K-Means and agglomerative hierarchical clustering are run on standardised trajectory features. The script chooses the K-Means cluster count from a small candidate range using silhouette score. The cluster labels are descriptive, not causal or evaluative judgements about states.

## Important interpretation notes

- The Kaggle series is CMIE-based and should not be treated as identical to official PLFS estimates.
- The sample spans a short period around 2019–2020; there is limited data for long-term forecasting.
- COVID-19 coincides with a major structural break. A model trained on earlier months may perform poorly during the shock.
- Aggregating rural and urban estimates uses estimated labour-force weights derived from employment and unemployment rate. This is a transparent approximation based on the fields available in the source.
- Do not claim causality from the clustering output.
